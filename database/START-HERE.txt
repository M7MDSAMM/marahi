مراحي حنان — ملف تحليل قاعدة البيانات
====================================

ابدأ بـ analyse-base-donnees.pdf، أو افتح نسخة HTML القابلة للتعديل.
التقرير يشرح بالعربية نموذج البيانات والمصطلحات التقنية بالفرنسية/الإنجليزية.

يشمل:
- 13 جدولًا، 132 حقلًا، 16 مفتاحًا أجنبيًا.
- MCD وMLD وMPD وERD، وقاموسًا لكل الحقول.
- 14 سيناريو، الصلاحيات وCRUD، حالات الطلب والرحية، وSequence لإنشاء الطلب.
- صور SVG قابلة للتكبير، PDF وJPG لكل رسم، ومصادر DOT وMermaid.
- SQL لإنشاء القاعدة، seed مشتق من 12 منتوجًا في React، واستعلامات وأمثلة معاملات.
- 22 اختبار سلامة SQL ناجحًا على MariaDB 10.4.32 داخل نسخة اختبار معزولة.
- خطة ربط الواجهة بالباك إند والفجوات والقرارات التي يجب حسمها.

طريقة الاستيراد عند تنفيذ الباك إند:
1. 01-schema.sql ينشئ قاعدة جديدة باسم marahi_hanan. لا تستعمله فوق قاعدة موجودة؛ غيّر اسم CREATE وUSE إذا كان الاسم مستخدمًا.
صور seed تشير إلى public/images في مشروع React الموجود؛ لا تتضمن SQL ملفات الصور نفسها.
2. 02-seed.sql اختياري، لقاعدة فارغة فقط، ويحتوي حسابات معطلة بلا كلمات مرور قابلة للاستعمال.
3. 03-queries.sql للقراءة.
4. 04-transaction-examples.sql أمثلة تعليمية تنتهي بـ ROLLBACK، وتتوقع بيانات seed.

لم نغيّر قواعد LAMPP الحالية، ولم نربط React بهذه القاعدة. يبقى تشغيل الواجهة محليًا كما هو.
الجداول والقيود مطابقة لملف SQL المجرب. صلاحيات API وانتقالات الحالات والتحقق من مجموع السطور تحتاج كود الباك إند؛ لا تفرضها Foreign Keys وحدها.
