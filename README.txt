MARAHI HANAN — مراحي حنان

مجلد المشروع المعتمد:
/home/mohammad/lampp/htdocs/marahi-hanan

frontend/ : واجهة React، الصور والخطوط، والنسخة المبنية dist.
database/ : تحليل قاعدة البيانات، SQL والديغرامات. الواجهة غير مربوطة بباك إند حاليًا.

التشغيل بواسطة LAMPP:
http://localhost/marahi-hanan/
الرابط يفتح frontend/dist. مسار Apache القديم يتصل بهذا المجلد بروابط رمزية، فلا توجد نسخة ثانية من الكود يتم تعديلها.

بعد أي تعديل:
cd /home/mohammad/lampp/htdocs/marahi-hanan/frontend
npm run build
ثم أعد تحميل الصفحة.

للتطوير:
npm run dev

تنظيم الكود:
src/pages/ : كل مجموعة صفحات في مجلدها (admin، account، catalog، contact، cart).
src/components/ : المكونات المشتركة مثل البطاقة والكمية والشعار.
src/components/home/ : مقدمة الصفحة الرئيسية.
src/hooks/ : hooks قابلة لإعادة الاستعمال.
src/services/storage.js : قراءة وكتابة بيانات العرض المحلي.
src/data/ : التصنيفات والمنتوجات وبيانات العرض منفصلة.
src/styles/ : CSS مقسم حسب الجزء مع ملفات للشاشات المختلفة.
public/images/catalog/ : صور المرجع الأصلية وصور العبوات الثلاث المحسّنة.
docs/ASSETS.txt : مصدر كل صورة وترخيصها.

النمط البسيط المستخدم:
فصل المنطق عن العرض (Container / Presentational).
مثال: useCheckout.js يتعامل مع حساب وتسجيل الطلب المحلي؛ CheckoutForm وCartSummary يعرضان الحقول والسلة.
useProductEditor.js يتعامل مع بيانات المنتوج ورفع الصورة؛ ProductEditor يعرض النموذج.
لا مكتبة إدارة حالة إضافية ولا طبقات معقدة. Context للحالة المشتركة وuseState للنماذج.

اللغات: فرنسي وعربي تونسي مع RTL.
المظهر: فاتح وداكن، الاختيار محفوظ محليًا.
الصور: نفس صور المرجع، مع تحسين صور البسيسة والزرير وعجينة الجلجلان. صور توضيحية للعرض وليست تصويرًا للمنتوجات الفعلية. الخلفية SVG من نفس رمز الشعار.

ملاحظة تشغيل:
السلة والطلبات والحساب والمواعيد نماذج تجريبية محفوظة في نفس المتصفح. تسجيل الدخول ليس نظام مصادقة حقيقيًا. يلزم باك إند قبل الاستخدام الفعلي.
