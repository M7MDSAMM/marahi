برومبت تنفيذ مشروع مراحي حنان
=============================

أنشئ واجهة أمامية لمشروع جامعي باسم «مراحي حنان / Marahi Hanan»، طاحونة عائلية في العالية، بنزرت، تونس. اعتمد الصور المرجعية في الهوية: بني داكن، ذهبي، بطاقات فاتحة، سنبلة وخطوط مريحة.

المطلوب كود سهل يستطيع طالب جامعي فهمه وشرحه وتعديله. استخدم React وVite وJavaScript وCSS عادي، مع React Router للتنقل. استعمل useState وuseEffect وContext بسيطاً للحالة المشتركة. لا تضف TypeScript أو Redux أو مكتبات تصميم ضخمة أو أنماط برمجية معقدة. سمّ الملفات والمتغيرات بوضوح، واكتب تعليقات قصيرة عند الحاجة فقط. لا تضف عبارات عن أدوات التوليد داخل كود التطبيق أو واجهته، ولا تضف أخطاء مقصودة.

أنشئ الصفحات التالية:
- الرئيسية: ثلاث شرائح ترحيبية، فئات الحبوب والمنتوجات التقليدية والفواكه الجافة، منتجات مفضلة، خطوات الطلب، وتعريف بالطاحونة.
- الحبوب: اختيار تفاعلي بين القمح والشعير والدرع والحمص والشوفان والذرة، مع معاينة الحبوب والوصول للخيارات.
- المنتوجات التقليدية والفواكه الجافة: بحث وتصفية وترتيب بالسعر.
- تفاصيل المنتج: صورة واسم باللغتين ووصف، أنواع وأوزان، كمية وسعر وإضافة للقفة.
- القفة والطلب: تعديل الكمية والحذف، المجموع، الاسم ورقم الهاتف، الاستلام أو التوصيل، العنوان عند التوصيل وملاحظة اختيارية، ثم تأكيد تجريبي ورقم مرجعي.
- حول الطاحونة، الاتصال، وطلب موعد لطحن حبوب الحريف.
- الدخول وإنشاء ملف تجريبي ونسيان كلمة السر ومسار تأكيده.
- الحساب: المعلومات والعنوان والطلبيات المحفوظة في هذا المتصفح.
- الإدارة: ملخص النشاط، إضافة وتعديل وحذف المنتجات مع رفع صورة، إدارة حالات الطلبات، وتأكيد أو رفض مواعيد الطحن وعرض رسائل الاتصال.

اجعل الموقع بالفرنسية والعربية، مع نصوص عربية قريبة من البيئة التونسية، وتغيير الاتجاه RTL/LTR واللغة في جميع الصفحات. اعرض الأسعار بالدينار التونسي بثلاث خانات عشرية. تحقق من رقم الهاتف التونسي من 8 أرقام مع أو بدون +216. اجعل الدفع عند الاستلام، مع استلام من المحل أو توصيل بسعر تقديري قابل للتأكيد.

أضف وضعاً فاتحاً ووضعاً داكناً، مع حفظ اختيار اللغة والوضع. اجعل جميع الصفحات مناسبة لشاشات الموبايل والتابلت والكمبيوتر، مع قائمة موبايل وجداول لا توسّع الصفحة. استخدم لمسات خفيفة كظهور الأقسام وانتقال البطاقات، واحترم تقليل الحركة والتركيز بلوحة المفاتيح.

حافظ على الشعار المبني من المرجع. أعد استخدام صور المرجع، وحسّن واقعية إضاءة وملمس صور العبوات دون تغيير شكلها أو محتواها. استعمل نفس رمز السنبلة كخلفية SVG هادئة بدل صورة الحقل، ووثّق أن صور المنتوجات توضيحية وليست تصويرًا للمحل. استعمل Font Awesome Free للأيقونات مع ترخيصها. خزّن الصور والخطوط محليًا. افصل منطق النماذج عن عرضها باستعمال custom hooks، وقسّم الصفحات لمكوّنات صغيرة ومفهومة. لا تترك مساحات صور فارغة أو أزراراً لا تعمل. أي معلومات أو أسعار مكملة تكون أمثلة واضحة.

لا تختَر باك إند الآن. استخدم بيانات JavaScript وlocalStorage لتشغيل نموذج الواجهة. وضّح أن الحساب والدخول والإدارة واسترجاع كلمة السر والطلبات تجريبية فقط، ولا ترسل رسائل أو طلبات فعلية ولا تخزّن كلمات المرور. أبقِ الربط المستقبلي بواجهة API سهلاً.

سلّم ملفات المشروع، تحليل نطاقه، وصف الحدود التجريبية، وتعليمات التشغيل بأوامر npm install وnpm run dev، وتحقق من البناء ومن المسارات المهمة والعرض على الهاتف وباللغتين والوضعين.
